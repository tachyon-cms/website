The reference lists everything TachyonCMS v0.1.0 offers, one subject per page, in tables you can scan. It describes; the [Docs](/) topic explains, and the [Tutorials](/tutorials) build something.

| Page | Covers |
|---|---|
| [HTTP API](/reference/http-api) | Every endpoint: who can call it, its parameters, body, response and errors, with a real example. |
| [Field types](/reference/field-types) | Every field type and option, the values each accepts, and the validation messages. |
| [Filters and sorting](/reference/filters) | Every `where` operator, which fields it works on, paths, sorting and limits. |
| [Configuration keys](/reference/config) | Every setting and `TACHYON_` environment variable, with types and defaults. |
| [Errors](/reference/errors) | The problem+json format, every status, and the common messages. |

Every example response on these pages came from a real TachyonCMS v0.1.0 server. IDs and timestamps differ on yours, tokens are shortened to `tcs_…` and `tcy_…`, and trimmed responses say so.

The commands of the `tachyon` binary are in the [CLI reference](/cli).
