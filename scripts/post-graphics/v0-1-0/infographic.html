Release · v0.1.0

v0.1.0 at a glance

A headless CMS in one Rust binary, backed by one Postgres database, with an API generated from the content types you define.

Get it

A binary

Linux x86_64 and arm64, both static. macOS on Intel and Apple silicon.

A Docker image

ghcr.io/tachyon-cms/tachyoncms:v0.1.0
Set TACHYON_DATABASE_URL and TACHYON_PUBLIC_URL. It serves on port 3000.

What's in it

Content types, over the API or in a file

tachyon schema export, diff and apply. Renames keep your data.

Queries that follow your links

where[author.name][equals]=Ann, cursors, and map points by distance.

Only what you ask for

select and populate trim responses. Virtual and join fields.

Sign-in, roles and API keys

Argon2id, breached passwords refused, lockout, scoped keys you can rotate.

Access rules down to a field

Compiled to SQL per caller, so a hidden document can't be found by filtering.

Errors that point at the problem

RFC 9457 problem+json, the exact field (links.0.url), a request ID.

Supply chain

  • SPDX SBOM per archive
  • cosign-signed checksums
  • build provenance
  • signed image
  • weekly Scorecard
  • DCO sign-off

Pre-alpha. The admin screen, rich text, drafts and media don't exist yet, so keep it off public networks for now.
