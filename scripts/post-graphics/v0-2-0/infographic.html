Release · v0.2.0

v0.2.0 at a glance

Pages built from blocks you define, and rich text you write as JSON or Markdown and read back however your site wants it.

Get it

A binary

Linux x86_64 and arm64, both static. macOS on Intel and Apple silicon.

A Docker image

ghcr.io/tachyon-cms/tachyoncms:v0.2.0
Upgrading from v0.1.0? Swap the binary or the image. The one migration runs by itself.

What's in it

Pages built from blocks

A blocks field holds rows of the types you define. Filter into them with layout.blockType.

Blocks you write once

A shared block ("kind": "block") works in every collection that names it.

Rich text, field by field

Headings, lists, tables, code, links and blocks in the text. Turn features on per field.

Write it in Markdown

{"format": "markdown", …} in. What can't convert is a 422 with its line.

Read it your way

?format=html, markdown or text, escaped, every link checked again.

Config mistakes stop at startup

A missing --config, a misspelt key or an origin that can't match. From @foothillsdigital.

Supply chain

  • SPDX SBOM per archive
  • cosign-signed checksums
  • build provenance
  • signed image
  • weekly Scorecard
  • DCO sign-off
